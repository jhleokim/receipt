# receipt v2.0

영수증의 날짜·장소·금액을 읽어 파일명으로 정리합니다.

- **영역 표시하기**를 켜고 여러 번 드래그하면 네모가 누적됩니다. 빨간 테두리와 불투명도 10%의 빨간 채움은 JPG·PDF 저장에도 적용됩니다.
- **새 영역의 항목**에서 자동 판단 또는 날짜·장소·금액을 선택할 수 있습니다. 영역 아래의 ×는 개별 삭제, **되돌리기**는 마지막 영역 삭제입니다.
- **표시 영역 다시 인식**은 원본 이미지 또는 고해상도로 다시 그린 PDF에서 각 영역을 잘라 확대 인식합니다. 지정한 항목을 우선하며, 여러 영역의 값이 충돌하거나 인식에 실패하면 해당 필드의 기존 값을 유지합니다. 인식 중 직접 수정한 값도 유지합니다.
- 영역이 없으면 **전체 다시 인식**으로 다시 읽습니다. PDF는 기존과 같이 첫 페이지만 처리합니다.

v2.0에서는 영수증 목록과 원본·수정란을 나란히 배치했습니다. 모바일에서는 세로로 이어집니다. 기존 아이보리·빨강·청록과 빨강 10% 강조를 유지합니다.

- OCR 엔진을 연속 작업에서 재사용하고, 1분 동안 사용하지 않으면 종료합니다. 원본 캔버스로 OCR 입력을 만들고 긴 변을 제한합니다.
- 영수증 삭제는 8초 안에 되돌릴 수 있습니다. 삭제 확정 후 이미지·PDF 자원을 정리합니다.
- 저장 시점의 값과 강조 영역을 사용하며, 이후 수정된 영수증에는 다시 저장이 필요하다고 표시합니다.
- 공유는 파일 준비가 끝난 뒤 **공유 앱 선택**을 눌러 엽니다. 재시도할 때는 준비한 파일을 재사용합니다. 공유를 지원하지 않는 환경이나 파일 형식은 **파일 저장**으로 받을 수 있고, 여러 파일은 한 장씩 저장합니다. 공유 앱에 파일을 전달한 것을 실제 메시지 전송 완료로 표시하지 않습니다.
- PDF 미리보기에서 1~4열과 확대율을 선택합니다. 긴 영수증의 빈 첫 페이지 문제를 수정했습니다.
- 휴대폰 사진은 비율을 유지해 축소합니다. 전송 실패 사진은 같은 전송 번호로 다시 보내므로 중복되지 않습니다.
- v2 전송은 PC 수신 확인 후 삭제합니다. QR 세션은 첫 연결부터 15분간 유효하며 재전송으로 연장되지 않습니다. 대기 사진은 20장, 한 번에 수신하는 사진은 3장으로 제한합니다. 이미 열린 v1 화면은 기존 수신 방식을 유지합니다.

화면 구조는 `public/index.html`, 스타일은 `public/styles.css`, 화면 동작은 `public/app.js`, 모바일 전송은 `public/upload.js`, OCR은 `public/receipt-ocr.js`로 분리했습니다.

추가 설치 없이 `node --test tests/*.test.cjs`로 OCR 교정·실패·충돌 처리, 드래그, 내보내기, PDF 배치, 이미지 비율 및 전송 프로토콜을 검증합니다. Cloudflare 런타임 검증은 `npx wrangler dev --local`로 실행합니다.
